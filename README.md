World news in one image — Saturday, 21 November 2026.

A make.fun entry for the bounty
[news-image-20261121](https://make.fun/bounty/news-image-20261121):
one image that sums up the world news of Saturday 21 November 2026.

The image is a newspaper-style front page with eight photo stories from
that day: Iran strikes Bahrain, "El Chapo Isidro" captured in Mexico, a
Russian missile hits Kryvyi Rih, the Trump–Xi–Putin summit in Shenzhen,
COP31 talks run past their deadline in Antalya, an AI stock sell-off, a
dengue breakthrough in Brazil, and a magnitude 6.8 earthquake off
Timor-Leste — plus a ticker with the ICJ's Myanmar genocide ruling, the
Sparta II ablaze in the Gulf of Finland, and the Serang factory fire.
The photos are AI-generated illustrations (no real press photos, no
identifiable people); all text is rendered with Python PIL and DejaVu
fonts, and every fact is verified.

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`, so both runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
