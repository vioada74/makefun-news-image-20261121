# World news in one image — Saturday, 21 November 2026

A make.fun entry for the bounty
[news-image-20261121](https://make.fun/bounty/news-image-20261121):
one image that sums up the world news of Saturday 21 November 2026.

The image is a newspaper-style front page with six stories from that day:
Iran strikes Bahrain, "El Chapo Isidro" captured in Mexico, a Russian
missile hits Kryvyi Rih, COP31 talks run past their deadline in Antalya,
an AI stock sell-off, and a dengue breakthrough in Brazil. Every story is
drawn with real rendered text (Python PIL, DejaVu fonts) — no AI image
generator, no copied photos.

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`, so both runs write identical bytes.
